AcDbEvalExpr::activated

C++

virtual void activated(
    AcDbEvalNodeIdArray& argumentActiveList
);

Description

Called on graph-resident nodes that become active.

This method is called by AcDbEvalGraph::activate(), or by AcDbEvalGraph::evaluate() when it is called with a non-null node activation arrray, on every node being activated by the call.

Parameters

Parameters Description
argumentActiveList Input array of AcDbEvalNodeId objects of the nodes being activated in the graph
