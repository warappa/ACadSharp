AcDbEvalExpr::evaluate

C++

virtual Acad::ErrorStatus evaluate(
    const AcDbEvalContext* ctxt
);

Description

Causes the expression represented by the node to be evaluated. Called for a graph-resident node when the node is visited during a call to AcDbEvalGraph::evaluate().

The default implementation does nothing and returns Acad::eOk. Any nonsuccessful result terminates the graph traversal.

Parameters

Parameters Description
ctxt Input pointer to the AcDbEvalContext object used for the graph evaluation; may be null
