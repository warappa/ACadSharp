AcDbEvalExpr::nodeId

C++

AcDbEvalNodeId nodeId() const;

Description

Returns the ID of the node.

When a node is added to a graph, it is assigned an ID that is unique among all nodes in the graph. If the node is not graph resident, the ID is AcDbEvalGraph::kNullNodeId.

Returns the ID of the node if it is graph resident. Returns AcDbGraph::kNullId if the node is not graph resident.
