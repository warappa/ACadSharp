AcDbEvalGraph::getGraph

C++

static Acad::ErrorStatus getGraph(
    AcDbDatabase* pDb, 
    const ACHAR* pKey, 
    AcDbEvalGraph** pGraph, 
    const AcDb::OpenMode mode
);

Description

Retrieves the graph from the database. This method provides the ability to associate a graph with a database instead of with a specific object in the database.

The calling application is responsible for calling close() on the returned graph when it is no longer needed.

Returns Acad::eOk if successful. Returns Acad::eKeyNotFound if the specified key could not be found.

Parameters

Parameters Description
pDb Input database from which to retrieve the graph
pKey Input key at which the graph is associated
pGraph Output graph at the specified key, or null if the graph does not exist
mode Input mode in which to open the graph
