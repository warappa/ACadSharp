createGraph Method

Overload List

Method Description
AcDbEvalGraph::createGraph (AcDbDatabase*, ACHAR*) Creates a graph for the database at the specified key. This method provides the ability to associate a graph with a database instead of with a specific object in the database.Returns Acad::eOk if successful.
AcDbEvalGraph::createGraph (AcDbObject*, ACHAR*) Creates a graph on the object at the supplied key. The object must be database resident.Returns Acad::eOk if successful. Returns eAlreadyInDb if the graph already exists on the object.
