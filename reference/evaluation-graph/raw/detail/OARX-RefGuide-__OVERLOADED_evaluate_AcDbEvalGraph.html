Method Description
AcDbEvalGraph::evaluate (AcDbEvalContext*, AcDbEvalNodeIdArray*) Evaluates the class by traversing the graph and invoking AcDbEvalExpr::evaluate() on all of the visited nodes.Applications can activate and evaluate nodes in one step by providing a non-null activatedNodes array pointer. Otherwise, applications must activate one or more nodes in the graph by calling AcDbEvalGraph::activate() before calling this method.Returns Acad::eOk if succssful. If any of the calls to AcDbEvalExpr::evaluate() fail, the error returned by AcDbEvalExpr::evaluate() is returned by this method.
