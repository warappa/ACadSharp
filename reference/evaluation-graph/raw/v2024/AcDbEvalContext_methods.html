AcDbEvalContext Methods

Methods

Method Description
getAt Returns an AcDbEvalContextPair stored in the context.The pair passed in should be initialized with the desired key to return in the context. If the key exists, pair is updated with the value from the context.Returns Acad::eOk if successful. Returns Acad::eKeyNotFound if no entry exists with the specified key.
insertAt Inserts an AcDbEvalContextPair into the context.If an AcDbEvalContextPair with the specified key already exists, it is replaced with the new pair.
newIterator Returns a new AcDbEvalContextIterator for the context.Returns a new AcDbEvalContextIterator. Callers must delete the iterator when it is no longer needed by calling delete().
removeAt Removes an AcDbEvalContextPair from the context.
