Приложение к "Тайнам подземелий Autodesk"

Заклинания (AutoLISP-функции) диггера Supermaxа

Можно загрузить и разархивировать файл visibility-add-rus.lsp с исходными текстами следующих функций А.Лазебного:
1. eval_graf_output - получение словаря ACAD_EVALUATION_GRAPH из пространства редактора блоков
2. visibility_add - добавление нового параметра Visibility
3. visibility-up - установка выбранного Visibility Set текущим
4. eddedd - включение ручек всех элементов текущего Visibility Set
5. tecuch_visibility - определение наименования текущего Visibility Set
6. blk-visib-param-auditor - проверка корректности словаря BLOCKVISIBILITYPARAMETER
7. element-sel-current-del - удаление выбранных элементов из текущего Visibility Set
8. element-all-current-del - удаление всех элементов из текущего Visibility Set
9. element-sel-current-insert - добавление в текущий Visibility Set выбранных элементов
10. visibility_clear - полная очистка текущего представления от всех элементов, динамических свойств и представлений
11. properties_add_all_visibility - установка видимости выбранных динамических свойств и ручек во всех представлениях всех Visibility Set-ов
12. sootvetstvie - определение соответствия указателя элемента в пространстве редактора блоков и словарей ACAD_EVALUATION_GRAPH и BLOCKVISIBILITYPARAMETER

А вот пример динамического блока с 10 параметрами видимости (vp01, vp02, ..., vp10):

Этот DWG-файл находится здесь. Для создания такого блока из обычного динамического блока с одним параметром видимости надо выполнить шаги:

    1. Загрузите файл visibility-add-rus.lsp в окне редактора блоков с вашим обычным динамическим блоком
    2. Добавьте новый параметр видимости с помощью (visibility_add)
    3. Перенесите в списке новый параметр видимости вверх с помощью (visibility-up)
    4. Добавьте и отредактируйте состояния видимости для параметра видимости
    5. Повторите шаги 2-4 для других параметров видимости
    6. Сохраните свой динамический блок
Наслаждайтесь!

17.02.09. Дополнение: функция move-properties перемещения вверх или вниз свойств в динамических блоках (например, в блоках для коммерческих изделий).

Примечание
Некоторые динамические блоки имеют много дополнительных свойств и пользователь не может видеть их все сразу в палитре свойств. Вы можете перенести вверх наиболее нужные свойства и сделать их видимость более удобной.
Запуск программы: (move-properties). Скачать можно отсюда.
